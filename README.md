# eBayMarketplace.biz Product Blog

A production-oriented Flask blog that imports curated products from **eBayMarketplace.biz**, generates original product buying guides, preserves eBay affiliate attribution, publishes SEO-ready pages, and connects to Google Search Console through OAuth 2.0.

## Included

- Responsive public product blog with search, categories, RSS, XML sitemap, canonical URLs, Open Graph metadata, and Article structured data
- Password-protected admin control center
- Product import from the eBayMarketplace.biz sitemap and Product JSON-LD
- Manual product entry when a source page cannot be imported automatically
- Random product selection that avoids recently used products when possible
- OpenAI article generation with a safe deterministic fallback when no API key is configured
- Draft, edit, publish, and unpublish workflow
- Affiliate link enforcement using `rel="sponsored noopener nofollow"`
- Contextual backlinks to eBayMarketplace.biz and the original curated product page
- Safe SEO audit and repair engine
- Google Search Console OAuth, property selection, performance data, sitemap submission, and indexed-URL inspection
- Encrypted OAuth token storage
- PostgreSQL support, SQLite local development, health checks, and Render Blueprint configuration
- Daily automation with database-level duplicate-run protection

## Local setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Export the values from `.env` in your shell or use an environment loader, then run:

```bash
flask --app app init-db
flask --app app run --debug
```

Open `http://localhost:5000/admin/login`.

## Required production settings

Set these in Render before the first production login:

- `ADMIN_PASSWORD`: strong unique password
- `SITE_URL`: the final `https://...` blog address, without a trailing slash
- `SECRET_KEY`: generated by the Blueprint
- `TOKEN_ENCRYPTION_KEY`: optional Fernet key; when omitted, the app derives one from `SECRET_KEY`

OpenAI is optional. Without `OPENAI_API_KEY`, the generator produces a structured deterministic buying guide. With a key, set `OPENAI_MODEL` to a model available to your OpenAI project.

## Google Search Console OAuth

1. Create or select a Google Cloud project.
2. Enable the Google Search Console API.
3. Configure an OAuth consent screen.
4. Create a **Web application** OAuth client.
5. Add this authorized redirect URI:

   `https://YOUR-BLOG-DOMAIN/admin/gsc/callback`

6. Set `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, and the exact same `GOOGLE_REDIRECT_URI` in Render.
7. Verify the blog property in Search Console.
8. Sign in to the blog admin panel and open **Search Console → Connect Google**.

For a URL-prefix property, include the trailing slash, such as `https://example.com/`. A Domain property uses `sc-domain:example.com`.

## Product import requirements

The importer performs best when eBayMarketplace.biz exposes:

- `/sitemap.xml`
- one URL per product or product collection
- Product JSON-LD containing name, image, description, offers, price, and currency
- a visible eBay affiliate link containing the campaign/tracking parameters

The importer never manufactures affiliate parameters. It stores the exact affiliate URL found on the source page. Pages without a detectable affiliate link are skipped; they can be entered manually from the Products screen.

## Automation

When `SCHEDULER_ENABLED=true`, the app runs one content cycle at `AUTOMATION_HOUR_UTC`:

1. Import or refresh products.
2. Generate `POSTS_PER_RUN` articles.
3. Save drafts or publish based on `AUTO_PUBLISH`.
4. Run the SEO audit.

Start with `AUTO_PUBLISH=false` until generated output has been reviewed.

## Render deployment

The included `render.yaml` provisions:

- one Python web service
- one PostgreSQL database
- generated application secret
- health checking at `/healthz`
- automatic deploys from the repository

Use the Render Blueprint flow and set all environment variables marked `sync: false`. The service will create tables on first startup. After deployment, set `SITE_URL` and `GOOGLE_REDIRECT_URI` to the final Render/custom-domain URL, then redeploy.

## Security notes

- Never commit API keys, OAuth secrets, passwords, or tokens.
- Keep the GitHub repository private.
- Search Console can report performance and indexing information; it cannot guarantee rankings or force ordinary product articles into Google’s index.
- Automatic SEO repair is intentionally limited to low-risk changes. Content expansion, duplicate topic targeting, and product-image problems remain manual review items.
